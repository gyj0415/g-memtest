# 自测题库站

这是静态网页，不需要服务器程序。线上由 GitHub `main` 自动发布到 [https://g-memtest.netlify.app/](https://g-memtest.netlify.app/)。

## 怎么刷题

打开网站 → 点科目分类 → 点一套题库开始。进度保存在这台设备的浏览器里，换手机不会自动同步。

## 导入自己的题库

点 **导入题库**：

- `.json`：只有题目
- `.zip`：题目 + 图片（转换器下载的就是这种）

导入后在「本地题库」里，只存在当前浏览器。

## 转换器

网站里的 **题库转换器** 可以把整理好的 md 转成题库，配图后请 **下载 ZIP**，再回到自测网站导入。

线上转换器不能改服务器上的内置题库。要写入电脑里的内置题库，需要在项目目录运行 `npm start`，再用 **制作题库** 页。说明见仓库根目录 `README.md`。
