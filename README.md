# g-memtest 自测题库

把课程题库做成网页来刷：选题库、答题、判分。进度存在当前浏览器里。

## 快速使用

### 本地打开

在项目目录执行：

```powershell
npm start
```

浏览器打开 [http://127.0.0.1:4173/](http://127.0.0.1:4173/)

- 自测网站：首页
- 题库转换器：`/converter.html`
- 制作题库（写入内置）：`/studio.html`，只有 `npm start` 后才有这个入口

### 做题

1. 点科目分类展开
2. 点一套题库开始
3. 答题、判分。练习记录保存在这台电脑的这个浏览器里

练习页可以按章节、题型筛选。题目带图时，图片右侧有滑条可以调大小。

### 导入一套题库（不改内置）

首页点 **导入题库**，选：

- `.json`：只有题目文本
- `.zip`：题目 JSON + 图片（转换器下载的就是这种）

导入后出现在「本地题库」，只在当前浏览器里，刷新不会丢。

## 本地创建题库

推荐格式（md 或直接粘贴）：

```text
题库分类：公务员考试
题库名称：第三节课练习题
章节：第一章
分类：单选题
题目：题干
选项：
A. 选项 A
B. 选项 B
C. 选项 C
D. 选项 D
答案：A
图片：图1.png
图片说明：可空
```

### 用制作页写入内置（本地）

1. `npm start`，打开自测网站，点 **制作题库**
2. 选 md 文件，或把上面这种文本粘进去
3. 需要配图就批量选择图片，文件名对应 `图片：` 后面的名字
4. 点 **预览题目**，用圆圈选题配图（绿=已有图，橙=还缺文件）
5. 点 **写入内置题库**
6. 回到自测网站刷新，内置列表里就能看到

同名题库会覆盖。制作页也可以删除一整套内置题库。

写入后的文件在：

- 题目：`site/banks/`
- 图片：`site/images/<题库id>/`

### 用转换器（本地或线上都能用）

打开 **题库转换器**，同样放入 md / 粘贴 / 配图。

- **本地** `npm start` 后，也可以点 **写入内置题库**
- **线上** 没有写入权限：点 **下载 ZIP**，再回自测网站用「导入题库」导入这个 zip

## 上线

线上地址：[https://g-memtest.netlify.app/](https://g-memtest.netlify.app/)

仓库已经接到 Netlify，发布目录是 `site/`。改完后推到 GitHub 的 `main`，站点会自动更新。不要用 GitHub Pages，也不用再打压缩包拖上去。

线上能刷题、能用转换器下载 ZIP、能导入 JSON/ZIP。不能在线上直接改电脑里的内置题库。
